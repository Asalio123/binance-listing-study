# Post-Listing Underperformance in Cryptocurrency Markets

**Evidence from every Binance USDT listing, 2021–2026**

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Reproducibility](https://img.shields.io/badge/verification-one--command-green)](build_cjsj.sh)

> What does a buyer earn who purchases every new Binance USDT listing at its
> listing-day close, when dead tokens are kept in the sample?

Most listing studies measure a market that no longer exists: live data feeds
silently drop every token that died, and headline event windows bundle the
pre-listing run-up into what a buyer can still get. This project rebuilds the
measurement **point-in-time from the raw [data.binance.vision](https://data.binance.vision)
archive** — 470 death-inclusive events, no survivors-only sampling — and
anchors outcomes where a retail buyer can actually act: the listing-day close.

## Key findings

**1. The fade.** From the listing-day close, the median token loses at every
horizon (month-block bootstrap CIs exclude zero throughout):

| Horizon | Median return | % positive |
|---|---|---|
| +1 day | −4.45% | 33% |
| +3 days | −8.87% | 27% |
| +7 days | **−11.45%** | 29% |
| +14 days | −14.51% | 29% |
| +30 days | −21.53% | 29% |

**2. Tokens and dollars tell different stories.** Weighted by day-0 USD
turnover, the median week-one loss deepens to **−28.72%** (BTC-adjusted
−35.46%) — while dropping delisted tokens moves the median by only +0.35 pp.
The money evaporates while the tokens still trade.

**3. The fade steepens with attention.** Median week-one return across day-0
turnover quintiles: −0.6% → −5.0% → −14.5% → −16.8% → −23.5% (gradient
−22.9 pp, CI excludes zero). The quietest quintile shows no fade at all.

**4. The premium is gone before trading opens.** Announcement timestamps
reconstructed from the exchange's own CMS API (468/470 events, minute-level,
cross-validated against the Telegram channel): +24.4% median over the three
days *before* the announcement on venues where the token already traded, and
+9.4% in the three *hours* before publication.

**5. The graveyard.** 73 true delistings: −28.5% on the announcement day,
−51.5% from the announcement-day close to the last trade, −98.3% listing to
grave (1% positive). Migration/rebrand notices — same genre, no death — gain
+7.9%.

**6. Pre-specified holdout.** Four directional predictions frozen under version
control *before* any Bybit price data entered the repository. On 415 Bybit
survivors: the fade replicates (−10.34%, BH-adjusted p = 8×10⁻¹⁴), first-week
extremes predict continuation (r = +0.37), and the volatility-predicts-fade
gradient fails — reported as a failure. An exploratory death-inclusive check on
566 Coinbase listings reproduces the fade almost exactly.

## Reproduce

One command re-checks every headline number from the committed data (offline):

```bash
bash build_cjsj.sh    # 20/20 checks against data/
```

Full pipeline (public anonymous endpoints only):

```bash
pip install -r requirements.txt
python src/build_calendar.py     # archive index -> listing calendars
python src/event_study.py        # price paths -> event-level returns
```
