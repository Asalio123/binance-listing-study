# Day-0 Microstructure — микроструктура дня листинга по минутным барам

Дата сборки: 2026-09-16. Скрипт: `src/day0_microstructure.py` (только локальный кэш `data/intraday_day0_cache/`, сеть не используется).
Источник: те же 470 daily 1m klines zip, что у `intraday_day0_build.md`; open_time нормализован по длине числа (13 цифр = мс, 16 = мкс с 2025).
Выход: `data/day0_microstructure.csv` (470 строк, 0 NaN по ключевым метрикам; min n_bars = 180, окна 5/15/60 мин всегда полные).

## Метод

- **Opening print premium**: `ret_min1` = close 1-й минуты / open 1-го бара − 1 («первая доступная цена» — market-order на открытии исполняется ближе к close первой минуты, чем к теоретическому open); `ret_open_h1`, `ret_open_day` — то же до close 1-го часа и дня.
- **Агрессия покупателей**: `tb_share_W` = Σ taker_buy_quote_volume / Σ quote_volume за окно W ∈ {5, 15, 60} минут (ratio-of-sums по барным суммам, не среднее барных долей).
- **Френтези**: `count_h1` = Σ сделок за 60 мин; `cpm_5` = сделок/мин в первые 5 мин; `cpm_rest` = сделок/мин с 6-й минуты до конца дня; `frenzy_ratio` = cpm_5 / cpm_rest.
- **Фейд**: `fwd_7` из `listing_events_enriched.csv`; spearman по всей панели (строк с trunc_7=1 в панели нет — sensitivity-вариант совпадает с основным дословно, n=470 в обоих).

## 1. Opening print premium

Медианы по 470 событиям [DATA]:

| метрика | медиана | p25 | p75 |
|---|---|---|---|
| ret_min1 (open → close 1-й мин) | **+38.1%** | +5.8% | +165.9% |
| ret_open_h1 (open → close 1-го часа) | +30.9% | +2.7% | +165.3% |
| ret_open_day (open → close дня) | +28.1% | +1.5% | +144.8% |

«Первая доступная цена» хуже теоретического open на медиане **+38% уже через 60 секунд** — и это больше, чем премия к close первого часа: пик дня сидит в первом баре (согласуется с time_to_peak_min = 0 из intraday-разбора), дальше цена на медиане только сдаёт. Покупка по рынку на открытии листинга — покупка почти в дневной пик.

## Вердикт

Гипотеза «агрессия покупателей в первый час → глубже фейд» в формулировке **доли тейкер-покупок не подтверждается**: rho положительный (+0.073), незначим (p = 0.11), квартили немонотонны, Q4 фейдит меньше всех. Дисбаланс направления сделок в первый час не несёт сигнала о последующей неделе.

Но гипотеза подтверждается в формулировке **интенсивности френтези**: темп сделок первого часа предсказывает фейд с rho = −0.284 при p = 3.8e-10, медианный fwd_7 монотонно ухудшается от −0.7% (тихие листинги) до −21.9% (самые горячие). Фейдит не «чрезмерная покупка против продажи», а сам перегрев потока сделок — что согласуется с hour1_volume_share из intraday-разбора, где направленного сигнала тоже не было.
